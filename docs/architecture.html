Personal Finance Agent · solution architecture

Deterministic first, LLM as fallback. The agent reads through user-scoped tools and never writes: every change, including committing an import, becomes a proposal that the server executes only after you approve it. All data stores are in Singapore. Numbers match the component tables in architecture.md §4.
